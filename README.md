# Nexo Dev: portfólio

Três projetos de demonstração, feitos para mostrar como trabalho. As empresas, produtos, preços e contatos são fictícios.

| Projeto | O que é | Tecnologia | Como ver |
|---|---|---|---|
| [`restaurante`](restaurante) | Site de restaurante com cardápio digital e painel para o dono atualizar pratos, preços e fotos | Node.js, Express, HTML, CSS e JavaScript | `npm install` e `npm start` |
| [`landing-curso`](landing-curso) | Página de vendas de um curso, com calculadora interativa e rastreamento configurável | HTML, CSS e JavaScript | Abrir `index.html` |
| [`financas`](financas) | App web de receitas e despesas, com gráficos, instalável no celular (PWA) | HTML, CSS e JavaScript | Servir a pasta e abrir no navegador |

Cada pasta tem um README com os detalhes, os limites do que foi feito e como configurar.

## Sobre

Sou desenvolvedor web e mobile, com mais de 2 anos de experiência em uma empresa de sistemas ERP. Fora do trabalho, desenvolvo projetos de automação com inteligência artificial em Python e Node.js, que estão em outros repositórios desta conta.
